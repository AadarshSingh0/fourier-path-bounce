Run the following files in this folder to generate data and plot the results. Reproduces Section-4.3 results.
1) mega_random_findbounce_runner_FIXED.wl -File used by Mathematica .nb file to generate FindBounce for random potential upto 50 fields cases.

2) FindBounce.nb - Runs the FindBounce algorithm for the choosen potential.

3) mega_random_cosmotransitions_check.py - Runs the cosmoTransition algorithm for the 50 field potential.

4) mega_random_jax_fourier.py - Runs the Fourier algorithm for the 50 field potential.

5) mega_random_coefficients.csv - Contains the coefficient values for the Potential.

6) plot_mega_random_comparison.py - Plots the time and action vs number of fields for three cases cosmoTransition, FindBounce and Fourier. It takes as input csv files generated by (2), (3) and (4) files.
