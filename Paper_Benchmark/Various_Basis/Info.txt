Run the following files in this folder to generate data and plot the results. Reproduces Section-4.4 results.

1) basis_comparison_jax.py - Python file to generate the action convergence results for various basis such as fourier, bspline_local, chebyshev, wavelet, Fourier + B_Spline hybrid for optibounce paper benchmark potential in 3 and 4 dimensions and also our extended 50 fields potential. This code creates a results folder and stores various result files there such as .npz, summary.csv, history.csv. 
Run this code using command - python3 basis_comparison_jax.py --run-mode optibounce_D3 for dimension 3 paper benchmark potential and python3 basis_comparison_jax.py --run-mode optibounce_D4 for dimension 4. We can choose the potential, basis, mode, npz options etc by using python3 basis_comparison_jax.py --run-mode optibounce_D3 --nphi 5,10,20 --basis fourier,bspline_local --no-npz

2) plot_basis_comparison_from_csv.py - This file takes as input the csv summary file generated from (1) code in results folder and plots action, time, no. of modes etc vs number of fields in the potential. All the plots are stored inside plots folder in the respective potential folders. Run this file using command -python3 plot_basis_comparison_from_csv_cli_FIXED.py --run-label optibounce_D3, change optibounce_D3 to other options optibounce_D4 or mega_random_D4 for other potentials.

3) mega_random_cosmotransitions_check.py - This file takes as input the .npz files generated by (1) to plot the optimized path for a basis. This file creates a path_plots folder inside the potential folder name. For example plots > optibounce_D3 > path_plots. Run command -> python3 plot_saved_basis_paths.py --run-mode optibounce_D3 \
  results/optibounce_D3/optibounce_n10_d3__fourier to create fourier optimized path for each mode or use command ->  python3 plot_saved_basis_paths.py --run-mode optibounce_D3 \
  results/optibounce_D3/optibounce_n10_d3__fourier \
  results/optibounce_D3/optibounce_n10_d3__bspline_local \
  results/optibounce_D3/optibounce_n10_d3__hybrid_fourier_bspline to compare paths from various basis for a given mode.

The .npz files are saved NumPy data files. They store the optimized path information for each case, basis, and mode number. For more details read "Info_Extended.md" file in the same folder. Input_data folder contains a csv file with coefficients for extended 50 fields potential.
