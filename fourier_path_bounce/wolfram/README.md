# Wolfram / FindBounce adapter

`FourierPathBounce.wl` is the generic boundary between Python-exported
Fourier path geometry and the external FindBounce solver.

It provides two public functions:

- `ImportFourierPathPoints[source, falseVacuum, trueVacuum]` imports and
  validates an open false-vacuum-to-true-vacuum path.
- `RunFindBounceWithFourier[potential, fields, falseVacuum, trueVacuum,
  dimension, source, options]` passes that path to the standard FindBounce
  calculation and returns its action, runtime, status, diagnostics, initial
  path, and solver object.

Mathematica or Wolfram Engine and an installed FindBounce package are required.
They are external dependencies and are not bundled with this repository.

## Workflow

1. Optimize and export the Fourier path in Python.
2. Define the potential, fields, vacua, and optional gradient in Wolfram.
3. Load `FourierPathBounce.wl`.
4. Call `RunFindBounceWithFourier`; FindBounce performs the final bounce
   calculation.

Run `python3 -m examples.reusable_findbounce_example` first, then the
following from the repository root:

```wolfram
Get[FileNameJoin[{
  Directory[], "fourier_path_bounce", "wolfram", "FourierPathBounce.wl"
}]];

fields = {x, y};
potential = 1/4 (x^2 - 1)^2 +
  1/2 (y - 0.35 (x^2 - 1))^2 - 0.1 x;
gradient = {D[potential, x], D[potential, y]};
falseVacuum = {-0.9456492739235919, -0.03701160775472421};
trueVacuum = {1.0466805318046022, 0.033439047480567696};
metadataFile = FileNameJoin[{
  Directory[], "example_output", "findbounce_K4",
  "initializer_metadata.json"
}];

result = FourierPathBounce`RunFindBounceWithFourier[
  potential, fields, falseVacuum, trueVacuum, 4, metadataFile,
  "Gradient" -> gradient,
  "FindBounceOptions" -> {"PathTolerance" -> 0.01},
  "TimeLimit" -> 120
];
Print[KeyDrop[result, {"Bounce", "InitialPath"}]];
```

The source may be an explicit numeric point matrix, a full-path CSV file, or
the metadata JSON generated by the Python exporter. In every case the path
must be open and ordered from false vacuum to true vacuum.

See
[`examples/reusable_findbounce_example.py`](../../examples/reusable_findbounce_example.py)
for geometry export and
[`examples/reusable_findbounce_example.wls`](../../examples/reusable_findbounce_example.wls)
